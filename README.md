# dashboard

Self-hosted dashboard for an IT landscape and a freelance business. It pulls data from **Kimai**, **Invoice Ninja**, **Snipe-IT** and **Dawarich**, shows it in the [shrippen Design Default](https://github.com/shrippen/shrippen.github.io) and turns it into hints and reminders. Shipped as a single Docker container.

Status: planning. See [ROADMAP.md](ROADMAP.md) (German).
