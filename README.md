# dashboard

Self-hosted, multi-user dashboard for an IT landscape and a freelance business. It replaces Dashy as the start page (links, status checks, search, RSS, clock, weather) and pulls data from **Kimai**, **Invoice Ninja**, **Snipe-IT** and **Dawarich** to turn it into hints and reminders.

- Own login, users and teams, permissions down to single widgets, personal layouts
- Built-in configuration editor with history, YAML import/export and a Dashy `conf.yml` import
- Theme system based on the [shrippen Design Default](https://github.com/shrippen/shrippen.github.io); the shrippen theme is the only one shipped
- Shipped as a single Docker container
